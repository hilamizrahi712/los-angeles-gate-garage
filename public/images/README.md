Drop your photos into the correct folder. The site code already references these paths.

## /og/
- `og-default.jpg` — Open Graph image, **must be 1200×630px**. Used when pages are shared on social media.

## Tips
- All images should be JPEG or WebP, not PNG (for file size)
- Hero images: 1400×700px minimum, 200–400KB
- Service images: 800×500px, 100–200KB
- Team photos: square crop, 400×400px minimum
- Compress all images with Squoosh (squoosh.app) before uploading
